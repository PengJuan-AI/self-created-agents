# Roadmap

## Phase 1 — organize

- Establish the agent folder and manifest convention.
- Catalog Drafter.
- Keep the current local Drafter app working.

## Phase 2 — make it a workbench

- Build a small Hub that reads the registry.
- Add an adapter interface and a run history model.
- Add validation for manifests, duplicate IDs, missing entrypoints, and invalid statuses.

## Phase 3 — make it presentable

- Add agent cards, examples, screenshots, and featured collections.
- Add public/unlisted visibility controls.
- Add a shareable detail page for selected agents.

## Phase 4 — make it dependable

- Add per-agent evaluation examples.
- Track versions and changelogs.
- Add logs, error handling, rate limits, and secret management before exposing agents publicly.
